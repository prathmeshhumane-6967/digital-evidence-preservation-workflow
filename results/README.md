# Results

This folder holds the **evidence of testing** for the project:

- `hash-demo-run-<UTC timestamp>/`: created automatically by `lab/hash-demo/hash_demo.sh`. It contains the fictional files, hash manifests, the timestamped action log, the T1–T5 summary and the full terminal transcript.
- `screenshots/`: screenshots of each demo step (file names are listed in `lab/hash-demo/README.md`).

Everything in this folder comes from the fictional demo data. No real evidence and no personal data are stored here.

The observed results are written up in Section 7.3 of `report/technical-report.md`.
